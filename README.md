# Simple Snake Game

A classic Snake game built using Python and Pygame.

## Features
- Classic snake movement using arrow keys.
- Grow the snake by eating green food.
- Score tracking.
- Game Over screen with restart option.

## Prerequisites
- Python 3.x installed.
- `pip` (Python package installer).

## Setup Instructions

1. **Install Pygame**:
   Open your terminal or command prompt and run:
   ```bash
   pip install -r requirements.txt
   ```
   *Or directly:*
   ```bash
   pip install pygame
   ```

2. **Run the Game**:
   In the terminal, navigate to the project directory and run:
   ```bash
   python snake.py
   ```

## How to Play
- Use **Arrow Keys** (Up, Down, Left, Right) to control the snake.
- Eat the **green** squares to grow and increase your score.
- Avoid hitting the screen boundaries or your own tail.
- If you lose, press **C** to play again or **Q** to quit.

Enjoy!
